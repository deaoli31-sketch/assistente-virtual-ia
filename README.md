# TechHelp IA

Assistente virtual para suporte técnico de primeiro nível.

## Funcionalidades
- Responde dúvidas sobre VPN
- Auxilia com Outlook
- Orienta sobre redefinição de senha

## Tecnologias
- Python
- JSON

## Estrutura
- data/: base de conhecimento
- docs/: documentação
- src/: código da aplicação

## Como executar
```bash
python src/app.py
```
